# Brand asset

`vodafone-logo.svg` is a local, code-native reproduction of Vodafone's public
horizontal logo for this approved hackathon demonstration. Its Speechmark,
wordmark, and Vodafone red (`#E60000`) follow the identity presented on
[Vodafone.com](https://www.vodafone.com/). Vodafone and the Vodafone Speechmark
are trademarks of Vodafone Group Plc.

Keeping the asset local avoids a runtime CDN dependency and ensures the demo
continues to render when offline.
